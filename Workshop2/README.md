ข้อที่ 1 — ฟังก์ชันคำนวณคะแนน
เกณฑ์การตัดเกรด (GRADE_THRESHOLDS): ประกาศ Array ของ Object กำหนดช่วงคะแนนและตัวอักษรเกรด เรียงลำดับจากคะแนนสูงสุดไปต่ำสุด  
การตรวจสอบคะแนน (isValidScore): ใช้ Arrow Function เช็คว่าคะแนนเป็นชนิดข้อมูลตัวเลข (number) และอยู่ในช่วง 0 ถึง 100 หรือไม่  
การแปลงคะแนนเป็นเกรด (toGrade): เรียกใช้ isValidScore ตรวจสอบความถูกต้องก่อนเสมอ หากคะแนนถูกต้อง จะใช้ .find() ค้นหาเกรดแรกที่คะแนนถึงเกณฑ์  
การคิดคะแนน Workshop (calculateWorkshopScore): คำนวณเทียบสัดส่วนคะแนนดิบด้วยสูตร (raw / full) * weight โดยใช้ Default Parameter กำหนดค่าเริ่มต้นเป็น full = 60 และ weight = 20  
การคำนวณคะแนนรวม (calculateTotal): รวมคะแนนทั้ง 5 ส่วน (Workshop, Entry/Attendance, Project, Midterm, Final) เข้าด้วยกัน  
การทดสอบและแสดงผล: คำนวณคะแนนรวมของนักศึกษา 3 คน แล้วนำมาจัดโครงสร้าง Object เพื่อแสดงผลลัพธ์เป็นตารางด้วย console.table() รวมถึงทดสอบการข้ามพารามิเตอร์ด้วย undefined เพื่อยืนยันการทำงานของ Default Parameter  

ข้อที่ 2 — ทะเบียนนักศึกษา
ข้อมูลตั้งต้น (studentList): สร้าง Array เก็บข้อมูลนักศึกษา 6 คน โดยมีโครงสร้าง Object ซ้อนอยู่ภายใน (contact)  
การค้นหาด้วย ID (findById): ใช้ .find() ค้นหา Object นักศึกษาที่รหัสตรงกับเงื่อนไข หากไม่พบจะ คืนค่า undefined
การกรองตามสาขา (findByMajor): ใช้ .filter() ค้นหานักศึกษาทั้งหมดในสาขาที่ระบุ แล้วคืนค่ากลับมาเป็น Array  
การเช็คคนสอบตก (hasFailingStudent): ใช้ .some() เช็คว่ามีนักศึกษาคนไหนได้คะแนนต่ำกว่า 50 หรือไม่ หากมีเพียงคนเดียวจะคืนค่า true ทันที  
การดึงอีเมลอย่างปลอดภัย (getEmail): ดึงข้อมูลนักศึกษาตาม ID แล้วใช้ Optional Chaining (?.) คู่กับ Nullish Coalescing (??) เพื่อดึงอีเมลโดยไม่เกิด Error หากไม่พบข้อมูลติดต่อ หรือหา ID ไม่เจอ  
การทดสอบและ Immutability: ทดสอบการค้นหาเคสที่ไม่มีในระบบ (เช่น ID '9999') และเพิ่มนักศึกษาใหม่เข้า Array ด้วย Spread Operator ([...]) แทนการใช้ .push() เพื่อรักษาข้อมูล Array ต้นฉบับไม่ให้ถูกแก้ไข  

ข้อที่ 3 — สรุปผลการเรียน
การดึงรายชื่อ (getNames): ใช้ .map() ดึงเฉพาะ property name ของนักศึกษาทุกคนออกมาเป็น Array ของข้อความ  
การกรองคนผ่าน (getPassedStudents): ใช้ .filter() คัดเลือกเฉพาะนักศึกษาที่มีคะแนนตั้งแต่ 50 คะแนนขึ้นไป  
การคำนวณคะแนนรวม (getTotalScore): ใช้ .reduce() รวมคะแนนของนักศึกษาทุกคน โดยกำหนดค่าเริ่มต้นเป็น 0 เพื่อป้องกัน Error เมื่อเจอ Array ว่าง  
การหาคะแนนเฉลี่ย (getAverageScore): นำผลรวมคะแนนมาหารด้วยจำนวนนักศึกษา มีระบบเช็คป้องกันกรณี Array ว่างเพื่อไม่ให้เกิดค่า NaN และใช้ .toFixed(2) จัดรูปแบบทศนิยม 2 ตำแหน่ง
การนับจำนวนตามเกรด (countByGrade): ใช้ .reduce() ร่วมกับฟังก์ชัน toGrade เพื่อจัดกลุ่มและนับจำนวนนักศึกษาในแต่ละเกรด โดยกำหนดค่าเริ่มต้นเป็น Object ว่าง {}
การหาคนได้คะแนนสูงสุด (getTopStudent): ใช้ .reduce() เปรียบเทียบคะแนนทีละคน เพื่อดึง Object นักศึกษาที่ได้คะแนนมากที่สุด โดยใส่ค่าเริ่มต้นเป็น undefined
การเชื่อมต่อฟังก์ชันบรรทัดเดียว (cePassedAverage): ใช้ Method Chaining (filter $\rightarrow$ map $\rightarrow$ reduce) เพื่อหาคะแนนเฉลี่ยเฉพาะนักศึกษาสาขา CE ที่สอบผ่านจบในบรรทัดเดียว  
การทดสอบ Edge Case (emptyList): เรียกใช้งานทุกฟังก์ชันด้วย Array ว่าง [] เพื่อทดสอบว่าโปรแกรมสามารถทำงานได้ราบรื่นโดยไม่เกิด Error
