1-1
ประกาศตัวแปรเก็บข้อมูลส่วนตัว ชื่อเล่น รหัสนักศึกษา อายุ สาขาวิชา และจำนวนวิชาที่ลงทะเบียน  
คำนวณปีที่จะเรียนจบโดยนำปีปัจจุบันมาบวกกับจำนวนปีที่เหลือ  
แสดงผลข้อมูลทั้งหมดในรูปแบบบัตรแนะนำตัวใช้ Template Literal  


1-2
สร้างตัวแปรให้ครบ 6 ชนิดข้อมูล string number boolean undefined null array และแสดงค่าคู่กับชนิดข้อมูลด้วยคำสั่ง typeof  
ทดสอบและอธิบายผลลัพธ์ของ typeof null, ตัวแปรที่ยังไม่ได้กำหนดค่า (undefined) และ typeof NaN  
แปลงข้อมูลข้อความให้เป็นตัวเลขด้วยคำสั่ง Number() เพื่อนำมาคำนวณทางคณิตศาสตร์ และบังคับแสดงผลทศนิยม 1 ตำแหน่งด้วย .toFixed(1)


1-3
กำหนดค่าคงที่สำหรับเกณฑ์คะแนนสูงสุด และประกาศตัวแปรเก็บคะแนนเก็บส่วนต่าง ๆ
คำนวณคะแนน Workshop ตามสัดส่วนของวิชา นำไปรวมกับคะแนนส่วนอื่น และคิดเป็นเปอร์เซ็นต์จากคะแนนเต็ม 100  
คำนวณหาคะแนนที่ยังขาดเป้าหมาย 80 คะแนน  
แสดงผลใบสรุปคะแนนทั้งหมดด้วย Template Literal กำหนดทศนิยม 2 ตำแหน่ง


1-4
สร้างฟังก์ชัน toGrade(score) เพื่อตรวจสอบคะแนนว่าอยู่ระหว่าง 0-100 หรือไม่
แปลงคะแนนตัวเลขเป็นเกรดตัวอักษร (A จนถึง F) แบบเรียงลำดับจากมากไปน้อยโดยใช้ if...else if
ใช้ลูป for...of ดึงข้อมูลคะแนน 13 รูปแบบจากอาร์เรย์มาทดสอบฟังก์ชันทั้งหมดในคราวเดียว 


1-5
สร้างฟังก์ชันที่ใช้ switch กำหนดราคาพื้นฐานตามเมนู และกำหนดตัวคูณราคาตามขนาดอาหาร (ธรรมดา พิเศษ จัมโบ้)  
สร้างอาร์เรย์เก็บรายการสั่งอาหาร 5 รายการ ซึ่งประกอบด้วยชื่อเมนู ขนาด และจำนวน  
ใช้ลูป for...of คำนวณราคาย่อยของแต่ละรายการ และบวกรวมเป็นยอดสุทธิเพื่อแสดงบิล


1-6
สร้างฟังก์ชัน login ตรวจสอบเงื่อนไขตามลำดับ ได้แก่ ชื่อผู้ใช้ รหัสผ่าน สถานะการระงับบัญชี อายุ และบทบาทผู้ใช้งาน (อาจารย์หรือนักศึกษา)  
ทดสอบระบบด้วย 6 สถานการณ์ เช่น การล็อกอินสำเร็จ รหัสผ่านผิด หรืออายุไม่ถึงเกณฑ์  
มีการระบุหมายเหตุด้านความปลอดภัยว่าต้องตรวจสอบชื่อและรหัสผ่านก่อนข้อมูลอื่นเพื่อป้องกันการคาดเดาหรือข้อมูลรั่วไหล
